# Campus Club and Travel Buddy Application

NodeJS + Express
======================

This is a NodeJS + Express application that provides a basic web server using NodeJS and Express.

## How to run

1. Install dependencies:
   `npm install`

2. Start the application:
   `npm run dev`

3. Open `http://localhost:3000` in your browser.

You can also test the server using:
`curl http://localhost:3000`
